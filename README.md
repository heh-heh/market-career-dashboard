# Market & Career Dashboard

개인적으로 확인하고 싶은 **주식 · 게임/IT 취업시장 · 개발 동향 · 신기술**을 한 곳에서 보는 개인용 리포트 대시보드입니다.

## 현재 구성
- 반응형 GitHub Pages 웹사이트
- 종합 / 주식 / 취업시장 / 개발 동향 / 신기술 탭
- 모바일 화면 대응
- GitHub Actions 기반 Pages 자동 배포
- MIT License

## 데이터 정책
현재 화면의 시장 수치와 일부 내용은 UI 프로토타입입니다. 실제 데이터를 연결할 때는 각 제공자의 이용약관과 라이선스를 준수하고, API 키·비밀값은 저장소에 커밋하지 않습니다.

## 향후 계획
1. 주가 데이터 API 연결
2. 반도체·게임·AI 뉴스 수집
3. 게임 개발자 채용 데이터 수집
4. 날짜별 JSON 리포트 저장
5. GitHub Actions 자동 갱신
6. 차트·검색·필터 추가

## 배포
`main` 브랜치에 push하면 GitHub Actions가 GitHub Pages에 배포합니다.
